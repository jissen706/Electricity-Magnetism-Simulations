# Molecular Model of Polarization — Interactive Module

Interactive module for **Chunk 5: Molecular Model of Polarization** (PHYS 151).

## How to run

Open **`molecular_polarization.html`** in a web browser (double-click the file or drag it into Chrome, Safari, Firefox, etc.). No server or install required.

## What’s inside

1. **Free vs. Bound charges** — Compare conductor (free electrons moving) vs dielectric (electrons bound to molecules). Toggle the “Material” dropdown.
2. **Polar vs. Nonpolar molecules** — See polar molecules (e.g. H₂O) align with **E** and nonpolar molecules develop an induced dipole. Use the “Molecule type” dropdown and “Field strength” slider.
3. **Bound surface charges** — Polarized slab with σᵢ⁺ and σᵢ⁻ on the surfaces and neutral bulk. Adjust “Polarization strength.”
4. **Opposing electric field** — **E₀**, **Eᵢ** (induced, opposing), and **E_net = E₀ − Eᵢ**. Sliders for external field and dielectric constant κ.

Use the top navigation to switch sections. Animations run continuously in the active section.
